How the algorithm works

1. Encode

Each feature subset becomes a chromosome: 12 bits, 1 = keep the feature.

2. Evaluate

A 5-NN classifier scores each subset; bigger subsets pay a penalty λ.

3. Evolve

Tournament selection, crossover and mutation create the next generation.

4. Optimize

Repeat until the last generation, then report the best feature mask.
